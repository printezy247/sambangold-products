# SamBangGold logo — transparent PNG pack

Every file has a real alpha channel: no background, no black tile, no matte.
Regenerated from vector outlines (the Anton type is converted to paths), so the SVGs beside
them in `assets/brand/` are the scalable masters — use those wherever vector is accepted.

## Which wordmark finish

- **duotone** — chrome SAMBANG + gold GOLD. The real wordmark. Dark backgrounds only.
- **gold** — flat `#D4AF37`. Dark or light backgrounds, print, stamps.
- **white** — flat white. Dark or photographic backgrounds.
- **black** — flat `#050505`. **Use this on white or light backgrounds** — the duotone and
  white versions vanish there.

## Sizing rules

Clear space on every side = the badge diameter ÷ 4. Below 96px the full badge muddies, so
switch to the monogram. Below 20px drop the ring dashes and use a flat gold circle with SBG.

Never stretch, recolour outside gold / chrome / white / black, add drop shadows to the type,
or re-set the name in another typeface.
